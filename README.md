# AI Material Board Generator（デモ版）

インテリアデザイン会社の営業・プレゼン担当者向けに、顧客の要望からコンセプトを決め、登録した商品でマテリアルボード（プレゼン資料用の素材ボード）を作るWebアプリの試作です。

このデモ版は **生成AIに接続していません**。コンセプト案・相性チェック・説明文は、入力内容からルールで作成します。

## 使い方

1. 案件一覧から「本社オフィス改装（サンプル）」を開く、または「新規案件」を作る
2. 要望入力 → コンセプト（3案から選択）→ 商品ライブラリ → 素材構成 → ボード編集 → プレビュー・出力
3. PNG（高解像度）・PDF（A4横）・平置きだけの正方形PNG で書き出す

## 主な機能

- 商品ライブラリ：商品ページURL・品番・画像（URLまたはアップロード）を登録し、「未確認／確認済み」と画像の利用条件を管理
- 素材構成：カテゴリごとに「採用・候補・除外」を設定
- ボードのテンプレート4種（Flat Lay／Editorial／Material Grid／Concept）
- Flat Lay：素材サンプルを平置きに重ねたコラージュ。画像生成AIを使わず決まった規則で配置するため、同じ商品・同じ順番なら毎回同じ配置になる
- 出力前チェック：未確認の情報、画像の利用条件、文字のはみ出しを確認

## データについて

- サンプルの商品・メーカー名・品番はすべて **架空のデータ** です。商品画像はアプリ内で生成した素材イメージです。
- 入力したデータは、開いたブラウザの中（localStorage）にだけ保存されます。サーバーには送られません。別の端末へ移すときは「データをJSONで書き出し／JSONから復元」を使ってください。
- 実在の商品を登録する場合は、各メーカーの画像利用条件を確認してください。

## 技術メモ

- 1ファイル（`index.html`）で動く静的ページです。PNG/PDF出力に [html2canvas](https://html2canvas.hertzen.com/) と [jsPDF](https://github.com/parallax/jsPDF) をCDNから読み込みます。
